## 📖 نظرة عامة

**MAVIC** أداة ذكاء اصطناعي تعمل كإضافة داخل **Autodesk Revit**، تقوم بتدقيق المخططات الإنشائية **آلياً** وفق متطلبات **أكواد البناء السعودية (SBC)**، وتُصدر تقريراً تفاعلياً ثنائي اللغة (عربي/إنجليزي) يحدد المخالفات مع اقتراح حلول عملية لكل منها.

### 🎯 المشكلة

| الطريقة التقليدية | المدقق الذكي MAVIC |
|---|---|
| ⏱️ 3 أيام عمل لتدقيق مخطط واحد | ⚡ ثوانٍ معدودة |
| 💰 15,000 ريال (مهندس × 3 أيام) | 💵 ~0 ريال (اشتراك SaaS) |
| ❌ هامش خطأ 15-20% | ✅ هامش خطأ <5% |
| 📋 مراجعة عشوائية لعينات | 🔍 تغطية 100% للعناصر |

### 💡 الحل

محرك قواعد هندسي مبني على **8 قواعد SBC إنشائية**، مدعوم بطبقة ذكاء اصطناعي تولّد **السبب الجذري + خطوات الإصلاح + أثر التكلفة + الأولوية** لكل مخالفة.

## 🚀 البدء السريع

### التثبيت

```bash
pip install -r requirements.txt
```

### التشغيل

```bash
# تشغيل التدقيق الكامل وإنتاج التقرير التفاعلي
python main.py --model sample_model.json --out compliance_report.html
```

### تشغيل الاختبارات

```bash
pytest test_rules.py -v
```

## 🎨 ميزات التقرير التفاعلي

- 📊 **لوحة KPI** بأربع بطاقات (عناصر مفحوصة، مخالفات، زمن، نسبة امتثال)
- 🌐 **رسم 3D تفاعلي** (Plotly) للنموذج مع تمييز العناصر المخالفة بالأحمر
- 🔍 **جدول قابل للفرز والتصفية** حسب الخطورة / معرّف العنصر
- 🆚 **مقارنة "قبل / بعد"** بين التدقيق اليدوي والآلي
- 🌍 **واجهة عربية RTL** مع خط Tajawal
- 📴 **يعمل بدون إنترنت** — Plotly مدمج inline

## 🧠 طبقة الذكاء الاصطناعي

تعمل بوضعين:

| الوضع | الشرط | المصدر |
|-------|-------|---------|
| **ONLINE** | وجود `OPENAI_API_KEY` | `gpt-4o-mini` |
| **OFFLINE** | غياب المفتاح أو فشل الاتصال | قاموس هندسي مدمج |

> **ملاحظة للعرض:** الأداة **لا تنكسر أبداً** — عند أي فشل تتحول تلقائياً إلى الوضع Offline.

## 🔌 تكامل Revit (اختياري)

الأداة مُصممة لتعمل كإضافة **pyRevit**:
1. تستخرج بيانات النموذج الإنشائي من Revit
2. تحوّلها إلى صيغة JSON الموحدة
3. تشغّل محرك MAVIC وتفتح التقرير تلقائياً

> للمتطلبات: Revit 2024+ و pyRevit.
